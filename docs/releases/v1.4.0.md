# Nook v1.4.0

_Released 2026-08-07_

Nook v1.4.0 introduces quick access pinning for notes and shortcuts in the floating command bar, customizable autostart settings, automated update checks, and daily task agenda notifications upon startup.

## Highlights

- **Pin notes and shortcuts**: Pin your most used notes and shortcuts directly to the floating command bar, neatly grouped by workspace for instant access.
- **Settings and autostart control**: Manage application preferences from the new Settings modal in the workspace sidebar, including an option to automatically launch Nook when you log into Windows.
- **Daily task agenda notifications**: Receive a system notification summarizing your tasks due today whenever Nook launches, helping you stay organized from the moment you start your work session.
- **Automatic update checker**: Nook automatically checks for new software releases once every 24 hours and provides native notifications with direct links to download updates.

## Improvements

- Added interactive pin icons and context menu toggles to note and shortcut cards.
- Added manual update check button with inline status feedback inside the Settings modal.
- Configured background startup mode so Nook launches quietly without stealing focus when Windows starts.
- Faster search responses, smoother window transitions, and lower memory overhead powered by a rebuilt background engine.

## Fixes

- Fixed system notification permissions to ensure toast notifications display reliably on Windows.
