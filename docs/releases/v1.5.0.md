# Nook v1.5.0

_Released 2026-08-09_

Nook v1.5.0 introduces scheduled task reminders with native system notifications, a streamlined floating command bar focused on quick access launching, and fixes for note loading.

## Highlights

- **Scheduled task reminders**: Set specific date and time reminders on tasks to receive native system notifications with calendar sound alerts when your tasks are due.
- **Streamlined floating command bar**: Search and launch your notes and shortcuts faster with a cleaner floating window focused entirely on quick access.

## Improvements

- Added automatic scroll centering in the task date time picker to highlight your selected hour and minute immediately when opened.
- Refined Dashboard upcoming deadlines stat card to accurately count active tasks that are not overdue.
- Set a fixed floating command bar window height at 420px for consistent search display.

## Fixes

- Fixed an issue where notes failed to load or display after application updates.
- Fixed automatic database migration execution on startup to ensure system tables stay up to date.
- Enhanced application error handling to prevent display glitches during backend communications.
